# 9A Notícias — Jornal digital

Site em formato de jornal (inspirado no G1) produzido como trabalho da disciplina de **Ciências** — turma 9º ano A. Edição especial sobre **Mulheres na Ciência**.

## 🚀 Como usar

1. Baixe todos os arquivos mantendo a estrutura de pastas.
2. Abra `index.html` no navegador — pronto, funciona offline.
3. Para publicar no GitHub Pages: crie um repositório, envie os arquivos e ative Pages em *Settings → Pages → Deploy from branch → main*.

## 🗳️ Enquete

A enquete "Qual mulher cientista mais te inspira?" é **real e funcional**:

- Os votos ficam salvos no `localStorage` do navegador de quem vota.
- Cada visitante conta como 1 voto; é possível trocar a escolha.
- As barras mostram porcentagem e número absoluto de votos.
- A enquete começa com uma contagem inicial (para demonstração) e vai somando os votos reais.
